One file per state or union territory, named by state code (for example BR.js). Built on 14 November 2026.
Each file is one line:
  SN_INST("BR",[[name,district,kind,management,code,pmv,website,extra], ...],{universityCode:[name,type], ...});
kind: U university, C college, S stand-alone institution, I ITI.  management: G government, A aided, P private, "" not recorded.
code: AISHE code (universities, colleges, stand-alone) or NCVT MIS code (ITIs).  pmv: 1 if on the PM-Vidyalaxmi list.
extra: university type (U); [relation, affiliating university code] (C); DGT 2026-27 grading score (I).
Sources: AISHE lists of universities and colleges and the PM-Vidyalaxmi list (AIKosh, last modified 15 Dec 2025);
the DGT Bharat Skills training-centre directory (read 14 Nov 2026); DGT grading scores for 2026-27 (1 Jun 2026).
